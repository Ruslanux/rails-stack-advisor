Стек

  • Rails8.1.2 / Ruby 4.0
  • РендерингSSR + Hotwire
  • ВьюхиPhlex (app/components) + ERB
  • БДPostgreSQL + pg_search
  • ФонSolid Trifecta + mission_control-jobs
  • Authbcrypt (встроенный подход) + OmniAuth
  • ПраваCanCanCan
  • СостоянияAASM для жизненного цикла заказа

HR-платформа с AI-агентами

33 модели · 54 контроллера · 45 таблиц · 1005 тестов

Мультиагентная автоматизация найма, интеграции с календарём и мессенджером

Стек

  • Rails8.1.x / Ruby 4.0
  • РендерингInertia.js + React 18 + TypeScript
  • АссетыVite Ruby (vite_rails) + Tailwind
  • БДPostgreSQL
  • ФонSolid Trifecta
  • AuthAuthentication Zero + OmniAuth
  • ПраваAction Policy
  • ПоискMeilisearch
  • AILLM-клиент, парсинг PDF и DOCX
  • ИнтеграцииКалендарь, мессенджер, S3
  • ПаттерныInteractor, Draper, dry-validation, сериализаторы + Oj

Платформа обучения программированию

8 моделей · 21 контроллер · 7 таблиц · 30 тестов

Песочница исполнения кода, тесты, геймификация, JSON API

Стек

  • Rails8.0.3 / Ruby 3.4
  • РендерингSSR + Hotwire, редактор кода как остров
  • БДPostgreSQL
  • ФонSolid Trifecta
  • AuthDevise (веб) + JWT (мобильный API)
  • APIJSON API с JWT для мобильных клиентов
  • КонтентMarkdown-рендеринг уроков
  • Защитаrack-attack (песочница исполняет пользовательский код)
  • НаблюдаемостьSentry + lograge
  • ДеплойKamal 2, отдельный workflow деплоя

Что выяснилось

  • Двойная аутентификация (сессии + JWT) в одном приложении — рабочая схема, если API версионирован
  • Исполнение пользовательского кода требует таймаутов, лимитов памяти и жёсткого rate limit
  • 8 моделей на серьёзный продукт — сложность была в сервисах, а не в схеме
