## Рендеринг

**SSR (Server-Side Rendering)** — HTML полностью формируется на сервере при каждом запросе и приходит в браузер готовым. Быстрый первый экран, полноценная индексация поисковиками. В Rails это дефолт: ERB или Phlex плюс Hotwire.

**CSR (Client-Side Rendering)** — сервер отдаёт почти пустой HTML, страницу собирает JavaScript в браузере. Медленнее первая загрузка, сложнее SEO, зато богатое клиентское состояние.

**SSG (Static Site Generation)** — страницы генерируются один раз на сборке. Ноль серверных расходов, идеальная скорость, но никаких пользовательских данных в рантайме. Этот сайт собран именно так — Jekyll на GitHub Pages.

**Гидратация (Hydration)** — процесс, при котором JavaScript «оживляет» пришедший с сервера HTML, навешивая обработчики и восстанавливая состояние компонентов.

## Hotwire

**Turbo Drive** — перехватывает переходы по ссылкам и отправку форм, подменяя `<body>` без полной перезагрузки. Ощущение SPA без единой строки вашего JS.

**Turbo Frames** — независимо обновляемый кусок страницы. Ссылка внутри фрейма меняет только его содержимое.

**Turbo Streams** — фрагменты HTML с инструкцией, что с ними сделать: `append`, `replace`, `remove`. Приходят в ответе на форму или через WebSocket.

**Stimulus** — минимальный JS-фреймворк: контроллеры привязываются к разметке через `data-controller`. Не управляет состоянием, а дополняет пришедший HTML поведением.

**Hotwire Native** — оболочка для iOS и Android, показывающая ваши же серверные вьюхи в нативном контейнере. Позволяет получить мобильное приложение без отдельной кодовой базы.

## Rails 8

**Solid Queue** — фоновые задачи в вашей БД вместо Redis. Дефолтный адаптер Active Job начиная с Rails 8. С 8.1 выполненные задачи архивируются, а не удаляются.

**Solid Cache** — кэш на диске через БД. Дешевле Redis по объёму: десятки гигабайт кэша перестают быть проблемой бюджета.

**Solid Cable** — Action Cable поверх БД вместо Redis pub/sub.

**Solid Trifecta** — все три вместе. Их появление означает, что новое Rails-приложение не требует Redis вообще.

**Propshaft** — пайплайн ассетов, пришедший на смену Sprockets. Не компилирует и не склеивает — просто добавляет хеш к имени файла.

**Importmap** — способ подключать JS-модули по URL без сборки. Ни node_modules, ни бандлера.

**Kamal** — деплой Docker-контейнеров на обычные серверы по SSH. Zero-downtime, автоматический TLS через kamal-proxy, откат одной командой.

**Thruster** — HTTP/2-прокси перед Puma: сжатие, кэширование статики, X-Sendfile. Ставится вместе с Rails 8.

## Архитектура

**Монолит** — одно приложение, один деплой, одна база. Для подавляющего большинства проектов — правильный выбор.

**Модульный монолит** — один деплой, но с жёсткими границами между модулями, которые проверяются инструментом (Packwerk), а не только на code review.

**Микросервисы** — отдельные приложения со своими БД. Оправданы размером организации, а не размером кодовой базы.

**SOA** — сервис-ориентированная архитектура: крупные сервисы вокруг бизнес-возможностей, обычно с общей шиной. Предшественник и более крупнозернистый родственник микросервисов.

**Inertia.js** — прослойка, позволяющая писать вьюхи на React или Vue, оставляя роутинг и контроллеры в Rails. API писать не нужно: контроллер отдаёт props напрямую.

## Паттерны

**Service Object** — класс на один бизнес-сценарий с методом `call`. Разгружает контроллеры и модели.

**Query Object** — класс, инкапсулирующий сложную выборку. Убирает из моделей многоэтажные `scope`.

**Form Object** — объект для формы, не совпадающей с моделью один в один: несколько моделей сразу или валидации, нужные только на одном экране.

**Policy Object** — класс, отвечающий на вопрос «можно ли этому пользователю сделать это». Основа Pundit и Action Policy.

**Decorator** — обёртка над моделью, добавляющая логику представления, чтобы не засорять модель методами форматирования.

**Идемпотентность** — свойство операции давать один и тот же результат при повторном выполнении. Критично для платежей: ретрай после таймаута не должен создавать второе списание. Технически — уникальный ключ операции с уникальным индексом в БД.

**Машина состояний (AASM)** — явное описание статусов и допустимых переходов между ними. Невалидный переход становится невозможным, а не «не должен случаться».

**N+1** — классическая проблема: один запрос за списком плюс по одному запросу на каждую связанную запись. Лечится `includes`, ловится гемом Bullet.

## Прочее

**Keyset (cursor) пагинация** — вместо `OFFSET` используется условие по последнему увиденному ключу. Время ответа не растёт с номером страницы и записи не «прыгают» при вставках.

**pgvector** — расширение PostgreSQL для хранения векторов и поиска по косинусной близости. База семантического поиска и RAG без отдельного векторного сервиса.

**RAG (Retrieval-Augmented Generation)** — подход, при котором перед обращением к языковой модели из базы достаются релевантные фрагменты и подкладываются в запрос.

**PWA** — веб-приложение, устанавливаемое на домашний экран, с манифестом, service worker и push-уведомлениями. Rails 8 генерирует заготовки в `app/views/pwa/`.
